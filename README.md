# AURIX 2.0 — Personal AI Desktop Assistant
**POWERED BY: AM VEYRONIX** | Creator & Owner: **Abdul Muheeb**

AURIX 2.0 (Advanced Unified Responsive Intelligence X) is a full-stack, bright glassmorphism Personal AI Command Center and Windows 10/11 Desktop Ecosystem designed for productivity, voice interaction, project architecture, creative generation, defensive cybersecurity, and 12-step autonomous self-healing.

## Key Capabilities
- **Bright Daylight Command Hub**: Clean `#F8FAFC` / `#EEF2F7` glassmorphism interface with Emerald (`#10B981`), Gold (`#D6AD60`), and Cyan (`#06B6D4`) highlights (with optional Dark Theme in Settings).
- **Interactive 6-State Voice Orb**: Reactive Web Audio `AnalyserNode` visualization across `READY`, `LISTENING`, `THINKING`, `SPEAKING`, `EXECUTING`, and `ERROR` states, plus natural British Male TTS & offline speech synthesis fallback.
- **Hardware-Aware Adaptive Modes**: Automatically detects installed RAM, CPU cores, and storage to recommend `Lightweight`, `Balanced`, or `Advanced` mode (CPU-only compatible for systems like Intel HD 3000 / 4GB–8GB laptops).
- **12-Step Self-Healing Architecture**: Scans Frontend, Backend, SQLite Database, Voice Engine, AI Router, File System, and Dependencies — creates backup snapshots in `data/backups/`, validates patches, and rolls back automatically on failure.
- **100% Free Local & Offline AI Support**: Works completely offline via SQLite knowledge base, local workspace editor, and optional local Ollama models (`http://127.0.0.1:11434`).
- **5-Module Creative & Development Studio**: Picture SVG/PNG + Canvas Editor, 4-Scene WebM Motion Video Studio, AI Writing Studio, Coding Diagnostics Studio, and Responsive HTML5 Website Generator.
- **Native Windows 10/11 Suite (`windows_native/`)**: Includes Python Core orchestration (`pc_controller.py`, `voice_engine.py`, `self_healer.py`, `security_argon2.py`), C# .NET 8 WPF desktop shell, and Inno Setup installer scripts.

## Owner Identity, Visual Learning & Activation (new)
- **OR-based owner authentication**: face (with blink liveness) **or** voice (challenge-phrase replay protection) **or** PIN unlocks the personal session. Templates are encrypted on the machine and matched by the local server.
- **TEACH AURIX**: floating ~1/8-screen camera preview (right by default, movable left, auto-minimizes after 60 s with a live indicator), object teaching with review-before-save, gesture teaching, custom voice tasks, and the AURIX Memory Center for approved examples.
- **Chrome/Gmail activation**: a local Chrome extension reports when Chrome starts or Gmail opens; AURIX then asks the owner to verify (only when locked). Windows autostart script included.
- Full details, privacy model, calibration numbers, test report and limitations: [`docs/AURIX_UPGRADE.md`](docs/AURIX_UPGRADE.md). Desktop bridge: [`desktop/README.md`](desktop/README.md).
